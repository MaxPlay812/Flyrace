# Clover 4 — Воздушные гонки

GUI-приложение для управления и мониторинга дрона **Clover 4** на соревнованиях по автономным воздушным гонкам (регламент РобоФинист, «Восьмёрка»).

## Возможности

| Модуль | Описание |
|--------|---------|
| **Управление полётом** | Взлёт/посадка, аварийная остановка, регулировка скорости |
| **Камера** | Живое видео с дрона, наложение обнаруженных ArUco маркеров |
| **Optical flow** | Визуализация потоков (CUDA/CPU авто-выбор) |
| **Карта поля** | 2D вид сверху: трек восьмёрки, столбы, позиция дрона, след полёта |
| **ArUco маркеры** | Добавление/редактирование маркеров, зоны скорости, генерация изображений для печати |
| **Счёт гонки** | Счётчик кругов, рестартов, очков; таймер 5 минут |
| **Симуляция** | Без дрона — автоматический полёт по маршруту для отладки карты |

## Быстрый старт

### macOS / Linux
```bash
pip install -r requirements.txt
./run.sh
# или напрямую:
python src/main.py
```

### Windows
```bat
pip install -r requirements.txt
run.bat
```

## Требования

```
Python 3.10+
PyQt5 >= 5.15
opencv-contrib-python >= 4.8   # нужен для ArUco
numpy >= 1.24
```

## Подключение к Clover 4

1. Подключитесь к WiFi дрона (`clover-XXXX` / `cloverwifi`)
2. Задайте переменные ROS:
   ```bash
   export ROS_MASTER_URI=http://192.168.11.1:11311
   export ROS_IP=<ваш IP>
   ```
3. Запустите приложение — оно автоматически определит ROS

Без ROS приложение работает в режиме **симуляции**.

## ArUco маркеры

Словарь: **4X4_50** (ID 0–49). Размер по умолчанию: 150×150 мм.

| Тип зоны | Цвет на карте | Действие |
|----------|--------------|---------|
| Нейтральная | Синий | Нет изменений |
| Ускорение | Зелёный | Установить заданную скорость |
| Замедление | Красный | Установить заданную скорость |
| Маршрутная точка | Жёлтый | Ориентир на карте |
| Старт/Финиш | Фиолетовый | Отметить позицию |

Маркеры можно распечатать прямо из вкладки **ArUco маркеры** → **Показать маркер**.

## CUDA-ускорение (Windows / Linux)

Для GPU-ускорения optical flow и обработки кадров нужен OpenCV с поддержкой CUDA:

```bash
# Проверить, есть ли CUDA в текущем OpenCV
python -c "import cv2; print(cv2.cuda.getCudaEnabledDeviceCount())"
```

Если `0` — стандартная pip-версия без CUDA. Для сборки с CUDA см. [`docs/BUILD.md`](docs/BUILD.md).

Приложение **автоматически** выбирает CUDA или CPU и показывает это в строке статуса и на кнопке Optical flow.

## Полигон (регламент РобоФинист)

- Поле: ≥ 4000 × 3000 мм
- Два столба на продольной оси, расстояние между ними 2000 мм
- Трасса — восьмёрка, радиус полукруга 500 ±250 мм (по центру столба)
- Высота полёта: 1–2 м
- Время заезда: 5 минут
- Очки: круги − рестарты
