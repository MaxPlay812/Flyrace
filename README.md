# Clover 4 — Воздушные гонки v1.1.0

GUI-приложение для управления и мониторинга дрона **Clover 4** на соревнованиях по автономным воздушным гонкам (регламент РобоФинист, «Восьмёрка»).

## Возможности

| Модуль | Описание |
|--------|---------|
| **Управление полётом** | Взлёт/посадка, аварийная остановка, регулировка скорости |
| **Камера** | Живое видео с дрона, наложение обнаруженных ArUco маркеров |
| **Optical flow** | Визуализация потоков (CUDA/CPU авто-выбор) |
| **Карта поля** | 2D вид сверху: трек восьмёрки, столбы, позиция дрона, след полёта |
| **ArUco маркеры** | Добавление/редактирование маркеров, зоны скорости, генерация для печати |
| **Счёт гонки** | Счётчик кругов, рестартов, очков; таймер 5 минут |
| **Симуляция** | Без дрона — автоматический полёт по маршруту для отладки |
| **Авто-настройка SSH** | Автоматическое исправление проблем clover-сервиса на дроне |
| **Поиск топиков** | Обнаружение всех ROS-топиков и сервисов; авто-определение неймспейса |

## Быстрый старт

### Linux/macOS (рекомендуется)
```bash
pip install -r requirements.txt
./run.sh          # автоматически настраивает ROS_IP
```

### Windows
```bat
pip install -r requirements.txt
run.bat
```

### Напрямую (без ROS)
```bash
python src/main.py
```

## Подключение к Clover 4

1. Подключитесь к WiFi дрона: `clover-XXXX` / `cloverwifi`
2. Запустите `./run.sh` — ROS_IP определяется автоматически
3. При проблемах — кнопка **«ROS: ...»** → вкладка **«Авто-настройка»**

Без ROS приложение работает в режиме **симуляции**.

### Авто-настройка (SSH-ремонт)

Если ROS-сервисы дрона недоступны, используйте встроенную авто-настройку:

```
Кнопка «ROS: ...» → вкладка «Авто-настройка» → «▶ Авто-настройка»
```

Выполняет 6 шагов по SSH:
1. Проверка SSH-доступности (`sshpass -p raspberry`)
2. Состояние `systemctl is-active clover`
3. Защита от crash-loop (если упал >8 раз — показывает журнал)
4. `systemctl restart clover`, ожидание до 13 с
5. Проверка регистрации ROS-сервисов на борту дрона
6. Вызов `get_telemetry` для верификации, проверка `armed`

Все ошибки сопровождаются конкретными инструкциями по исправлению.

### Автоопределение неймспейса

Если clover запущен в нестандартном неймспейсе (не `/clover`), контроллер
автоматически обнаружит правильный путь через XML-RPC и подключится.

Для постоянной настройки:
```bash
export CLOVER_NS=имя_неймспейса   # или оставьте пустым для /clover
```

## ArUco маркеры

Словарь: **4X4_50** (ID 0–49). Размер по умолчанию: 150×150 мм.

| Тип зоны | Цвет | Действие |
|----------|------|---------|
| Нейтральная | Синий | Нет изменений |
| Ускорение | Зелёный | Установить заданную скорость |
| Замедление | Красный | Установить заданную скорость |
| Маршрутная точка | Жёлтый | Ориентир на карте |
| Старт/Финиш | Фиолетовый | Отметить позицию |

Маркеры можно распечатать из вкладки **ArUco маркеры → Показать маркер**.

## CUDA-ускорение

```bash
# Проверить
python -c "import cv2; print(cv2.cuda.getCudaEnabledDeviceCount())"
```

Если `0` — CPU-режим. Для GPU см. [`docs/BUILD.md`](docs/BUILD.md).  
Приложение **автоматически** выбирает CUDA или CPU.

## Полигон (регламент РобоФинист)

- Поле: ≥ 4000 × 3000 мм
- Два столба, расстояние 2000 мм по оси
- Трасса — восьмёрка, радиус 500 ±250 мм
- Высота полёта: 1–2 м
- Время заезда: 5 минут
- Очки: круги − рестарты
